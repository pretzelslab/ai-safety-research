# Benchmark

Controlled evaluation: 4 reference system profiles x 14 adversarial scenarios = 56 scored pairs.

The benchmark answers one question for each (system, scenario) pair:
**Given this system's sensing architecture, what is its ZIDR under the adversary conditions of this scenario?**

---

## Quick Start

```bash
cd womens_safety_adversarial

pip install -r benchmark/requirements.txt

# Run the full benchmark
python benchmark/benchmark_runner.py

# Skip CSV export (terminal output only)
python benchmark/benchmark_runner.py --no-csv

# Write CSVs to a custom directory
python benchmark/benchmark_runner.py --output-dir my_results/

# Use custom weights
python benchmark/benchmark_runner.py --weights my_weights.yaml
```

---

## Output

The runner produces four outputs:

1. **Terminal: ZIDR matrix** — colour-coded table, scenarios x systems, with per-row averages
2. **Terminal: overall score matrix** — weighted composite across all evaluation dimensions
3. **Terminal: governance gap summary** — total and average flags per system
4. **`results/benchmark_results.csv`** — 56-row full results
5. **`results/zidr_matrix.csv`** — ZIDR matrix only (paper Table 1)

Score key: `✓` LOW RISK (>=0.8)  `~` MODERATE (0.6-0.8)  `✗` HIGH / CRITICAL (<0.6)

## Evaluation Dimensions

ZIDR is one of five dimensions scored for each (profile, scenario) pair.
Scores are weighted by scenario category (urban/rural/sociotechnical):

| Dimension | What it measures |
|-----------|-----------------|
| ZIDR | Passive-layer robustness under L0 adversary |
| Vision robustness | Camera modality under occlusion/low-light attacks |
| Audio robustness | Microphone under noise suppression attacks |
| Sensor fusion | IMU + GPS under corruption/spoofing attacks |
| Governance | Coverage of missing regulatory requirements |

The **overall score** is a weighted composite of all five dimensions.
The **ZIDR score** is the primary metric reported in the paper.

## Adding Your Own System

1. Copy `profiles/example_profile.yaml` and fill in your system's modality
   capabilities, claimed accuracy figures, and certification status.
2. Add it to the `PROFILES` list in `benchmark_runner.py`.
3. Run `python benchmark/benchmark_runner.py` — your system appears as a new column.
